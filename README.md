# 🚀 Amith Baragi — Personal Portfolio

A modern, responsive, and interactive personal portfolio website built to showcase my skills, technologies, projects, and contact information.

The portfolio features a dark developer-focused design, animated sections, custom cursor effects, responsive navigation, project cards, skill progress bars, social links, and an EmailJS-powered contact form.

## 📧 Contact Form

The portfolio includes an interactive contact form powered by **EmailJS**.

Visitors can submit:

* Name
* Email address
* Message

The form sends the message directly through the configured EmailJS service.

> **Security Note:** EmailJS public keys can be used in frontend applications, but sensitive credentials such as private API keys or server-side secrets should never be placed directly in the HTML/JavaScript source.

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/amith6491-netizen/portfolio.git
```

### 2. Open the project folder

```bash
cd portfolio
```

### 3. Run the website

Since this is a frontend project, you can simply open:

```text
index.html
```

in your browser.

For a better development experience, you can use **VS Code Live Server**.
